# AtCoderでよくあるパターンと解法テクニック

AtCoderなどの競技プログラミングコンテストでは、同じような問題パターンが繰り返し出題されることがあります。このドキュメントでは、よく見られる問題パターンとその効率的な解法テクニックを紹介します。

## 1. 累積和（Cumulative Sum）

連続する区間の和を高速に計算するテクニック。O(1)で任意の区間の和を求められる。

```python
# 累積和の構築: O(N)
A = [1, 5, 9, 7, 5, 3, 2]
cumsum = [0] * (len(A) + 1)
for i in range(len(A)):
    cumsum[i + 1] = cumsum[i] + A[i]

# 区間[l, r)の和を求める: O(1)
def get_range_sum(l, r):
    return cumsum[r] - cumsum[l]

# 例: インデックス1から4までの和（5+9+7=21）
print(get_range_sum(1, 4))  # 21
```

### 応用例
- 2次元累積和（矩形領域の和）
- いもす法（区間加算のクエリ処理）
- 特定の値以下/以上の要素がいくつあるかのカウント

## 2. 二分探索（Binary Search）

ソートされた配列から値を高速に探索するアルゴリズム。条件を満たす値の境界を見つけるのにも利用できる。

```python
# bisectを使った二分探索
from bisect import bisect_left, bisect_right

A = [1, 3, 3, 5, 7, 10, 12]
pos = bisect_left(A, 5)  # 3: 値5が最初に現れる位置
pos = bisect_right(A, 3)  # 3: 値3より大きい最初の位置

# 値xが存在するかを確認
def binary_search(arr, x):
    i = bisect_left(arr, x)
    return i != len(arr) and arr[i] == x

# 特定の値の個数を数える
def count_elements(arr, x):
    return bisect_right(arr, x) - bisect_left(arr, x)
```

### 応用例
- 「○○以下の最大値」「○○以上の最小値」を求める
- 条件を満たす/満たさないの境界を見つける
- 二分探索で解の判定（二分法）

## 3. 座標圧縮（Coordinate Compression）

値の大小関係だけが重要で、実際の値はあまり意味をなさない場合に、値を小さな整数に置き換えるテクニック。

```python
# 座標圧縮
def compress(arr):
    # 重複を除去し、ソート
    sorted_set = sorted(set(arr))
    # 圧縮後の値を辞書で管理
    comp_dict = {val: i for i, val in enumerate(sorted_set)}
    # 圧縮
    compressed = [comp_dict[val] for val in arr]
    return compressed, sorted_set

A = [100, 30, 500, 30, 100, 20]
compressed, original = compress(A)
print(compressed)  # [2, 1, 3, 1, 2, 0]
```

### 応用例
- 配列の値が非常に大きい場合のインデックス変換
- 値の種類数を削減してアルゴリズムを適用

## 4. グラフ探索（DFS/BFS）

グラフや木構造、グリッド上の探索に使用される基本アルゴリズム。

### 深さ優先探索（DFS）

```python
# 隣接リスト表現のグラフでのDFS
def dfs(graph, start, visited=None):
    if visited is None:
        visited = set()
    visited.add(start)
    print(start, end=' ')  # 訪問順に出力
    
    for next_node in graph[start]:
        if next_node not in visited:
            dfs(graph, next_node, visited)

# 再帰を使わないDFS
def dfs_iterative(graph, start):
    visited = set()
    stack = [start]
    while stack:
        vertex = stack.pop()
        if vertex not in visited:
            visited.add(vertex)
            print(vertex, end=' ')
            stack.extend(reversed([n for n in graph[vertex] if n not in visited]))
```

### 幅優先探索（BFS）

```python
from collections import deque

# 隣接リスト表現のグラフでのBFS
def bfs(graph, start):
    visited = set()
    queue = deque([start])
    visited.add(start)
    
    while queue:
        vertex = queue.popleft()
        print(vertex, end=' ')  # 訪問順に出力
        
        for next_node in graph[vertex]:
            if next_node not in visited:
                visited.add(next_node)
                queue.append(next_node)
```

### 応用例
- 最短経路探索（BFS）
- 連結成分の列挙
- グリッド上の探索（迷路など）
- トポロジカルソート（DAG）

## 5. 尺取法（Two Pointers）

配列上を左右のポインタで区間を管理し、効率的に探索するテクニック。

```python
# 連続する部分列の和がS以上になる最小の長さを求める
def min_subarray_len(nums, S):
    n = len(nums)
    left = 0
    sum_val = 0
    min_len = float('inf')
    
    for right in range(n):
        sum_val += nums[right]
        
        # 和がS以上になったら左ポインタを進める
        while sum_val >= S:
            min_len = min(min_len, right - left + 1)
            sum_val -= nums[left]
            left += 1
    
    return min_len if min_len != float('inf') else 0
```

### 応用例
- 部分列の最大/最小の長さを求める
- 条件を満たす部分列の数を数える
- しゃくとり法（区間を伸縮させる）

## 6. Union-Find（素集合データ構造）

グループ分けを効率的に管理するデータ構造。要素の結合と、2つの要素が同じグループに属するかの判定を高速に行える。

```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n
        self.size = [1] * n
        self.count = n  # 連結成分の数
    
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])  # 経路圧縮
        return self.parent[x]
    
    def union(self, x, y):
        root_x = self.find(x)
        root_y = self.find(y)
        
        if root_x == root_y:
            return False
        
        # ランクが低い方を高い方に結合
        if self.rank[root_x] < self.rank[root_y]:
            self.parent[root_x] = root_y
            self.size[root_y] += self.size[root_x]
        else:
            self.parent[root_y] = root_x
            self.size[root_x] += self.size[root_y]
            if self.rank[root_x] == self.rank[root_y]:
                self.rank[root_x] += 1
        
        self.count -= 1  # 連結成分が1つ減る
        return True
    
    def is_same(self, x, y):
        return self.find(x) == self.find(y)
    
    def get_size(self, x):
        return self.size[self.find(x)]
```

### 応用例
- グラフの連結性判定
- クラスカル法（最小全域木）
- グループ分けの動的管理

## 7. 動的計画法（DP）のパターン

問題を部分問題に分割し、その解を再利用するアルゴリズム設計手法。

### ナップサック問題（部分和問題）

```python
# 部分和問題: 配列から選んで合計をSにできるか
def can_make_sum(nums, S):
    dp = [False] * (S + 1)
    dp[0] = True  # 空集合で合計0は作れる
    
    for num in nums:
        for i in range(S, num - 1, -1):
            dp[i] |= dp[i - num]
    
    return dp[S]
```

### 最長増加部分列（LIS）

```python
# 最長増加部分列の長さを求める（二分探索版 O(N log N)）
from bisect import bisect_left

def longest_increasing_subsequence(arr):
    if not arr:
        return 0
        
    lis = [arr[0]]
    for num in arr[1:]:
        if num > lis[-1]:
            lis.append(num)
        else:
            pos = bisect_left(lis, num)
            lis[pos] = num
            
    return len(lis)
```

### 編集距離（レーベンシュタイン距離）

```python
# 編集距離を求める（文字列A→Bへの変換に必要な最小操作回数）
def edit_distance(A, B):
    m, n = len(A), len(B)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    
    # 初期化
    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j
    
    # DP遷移
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if A[i-1] == B[j-1]:
                dp[i][j] = dp[i-1][j-1]
            else:
                dp[i][j] = 1 + min(dp[i-1][j],      # 削除
                                   dp[i][j-1],      # 挿入
                                   dp[i-1][j-1])    # 置換
    
    return dp[m][n]
```

### 応用例
- 最長共通部分列（LCS）
- 区間DP（行列の連鎖積など）
- 桁DP（数の性質を利用するDP）
- 状態圧縮DP（ビット表現を使ったDP）

## 8. 数学的テクニック

### 素数判定と素因数分解

```python
# 素数判定（O(√N)）
def is_prime(n):
    if n <= 1:
        return False
    if n <= 3:
        return True
    if n % 2 == 0 or n % 3 == 0:
        return False
    i = 5
    while i * i <= n:
        if n % i == 0 or n % (i + 2) == 0:
            return False
        i += 6
    return True

# 素因数分解（O(√N)）
def prime_factorize(n):
    factors = []
    # 2による割り切れる回数を求める
    while n % 2 == 0:
        factors.append(2)
        n //= 2
    
    # 3以上の奇数で割っていく
    i = 3
    while i * i <= n:
        while n % i == 0:
            factors.append(i)
            n //= i
        i += 2
    
    # 最後に残った数が1より大きければ素数
    if n > 1:
        factors.append(n)
    
    return factors
```

### 約数列挙

```python
# 約数を列挙（O(√N)）
def divisors(n):
    divs = []
    i = 1
    while i * i <= n:
        if n % i == 0:
            divs.append(i)
            if i != n // i:  # 重複を避ける
                divs.append(n // i)
        i += 1
    return sorted(divs)  # 昇順にソート
```

### 最大公約数と最小公倍数

```python
# 最大公約数（ユークリッドの互除法）
def gcd(a, b):
    while b:
        a, b = b, a % b
    return a

# 最小公倍数
def lcm(a, b):
    return a * b // gcd(a, b)

# Pythonの標準ライブラリを使う場合
import math
math.gcd(12, 18)  # 6
math.lcm(12, 18)  # 36（Python 3.9以上）
```

## 9. ビット操作テクニック

### ビットカウント（1の数を数える）

```python
# 立っているビット数を数える
def count_bits(n):
    count = 0
    while n:
        count += n & 1
        n >>= 1
    return count

# Pythonの組み込み関数を使う
bin(12).count('1')  # 2（12は1100なので1が2つ）
```

### ビット全探索

```python
# ビット全探索（部分集合の列挙）
def bit_search(arr):
    n = len(arr)
    results = []
    
    for bit in range(1 << n):
        subset = []
        for i in range(n):
            if bit & (1 << i):
                subset.append(arr[i])
        results.append(subset)
    
    return results
```

## 10. ダブリングテクニック

2^k回の操作結果をあらかじめ計算しておくことで、任意の回数の操作を高速に行うテクニック。

```python
# LCA（最近共通祖先）をダブリングで求める例
def preprocess_lca(adj, root):
    n = len(adj)
    depth = [0] * n
    parent = [[-1] * n for _ in range(20)]  # 2^20 > 10^6
    
    def dfs(v, p, d):
        parent[0][v] = p
        depth[v] = d
        for u in adj[v]:
            if u != p:
                dfs(u, v, d + 1)
    
    dfs(root, -1, 0)
    
    # ダブリング
    for k in range(19):
        for v in range(n):
            if parent[k][v] != -1:
                parent[k + 1][v] = parent[k][parent[k][v]]
    
    return parent, depth

def lca(u, v, parent, depth):
    # uとvの深さを合わせる
    if depth[u] < depth[v]:
        u, v = v, u
    
    # uを持ち上げる
    for k in range(19, -1, -1):
        if depth[u] - depth[v] >= (1 << k):
            u = parent[k][u]
    
    if u == v:
        return u
    
    # 共通祖先を探す
    for k in range(19, -1, -1):
        if parent[k][u] != parent[k][v]:
            u = parent[k][u]
            v = parent[k][v]
    
    return parent[0][u]
```

## 11. 文字列処理の典型パターン

競技プログラミングでは文字列処理問題も頻出です。以下に典型的なパターンとその解法を示します。

### 11.1 文字列の検索と部分文字列のカウント

```python
# 文字列内の部分文字列の出現回数を数える
def count_substring(text, pattern):
    count = 0
    i = 0
    while i < len(text):
        pos = text.find(pattern, i)
        if pos == -1:
            break
        count += 1
        i = pos + 1  # 重複カウントする場合
        # i = pos + len(pattern)  # 重複カウントしない場合
    return count

# 例
text = "ababababa"
pattern = "aba"
print(count_substring(text, pattern))  # 4 (重複あり)
```

### 11.3 ランレングス圧縮と復元

```python
# ランレングス圧縮（連続する文字を「文字+個数」に変換）
def run_length_encode(s):
    if not s:
        return []
    
    result = []
    current_char = s[0]
    count = 1
    
    for i in range(1, len(s)):
        if s[i] == current_char:
            count += 1
        else:
            result.append((current_char, count))
            current_char = s[i]
            count = 1
    
    result.append((current_char, count))
    return result

# ランレングス復元
def run_length_decode(encoded):
    return ''.join(char * count for char, count in encoded)

# 例
s = "aaabbbccdaa"
encoded = run_length_encode(s)  # [('a', 3), ('b', 3), ('c', 2), ('d', 1), ('a', 2)]
decoded = run_length_decode(encoded)  # "aaabbbccdaa"
```

### 11.4 ローリングハッシュ（文字列のハッシュ化）

```python
# ローリングハッシュ（文字列の高速比較・検索用）
def compute_string_hash(s, base=31, mod=10**9 + 7):
    h = 0
    for c in s:
        h = (h * base + ord(c)) % mod
    return h

# 複数の部分文字列のハッシュを効率的に計算
def compute_substring_hashes(s, length, base=31, mod=10**9 + 7):
    n = len(s)
    if n < length:
        return []
    
    # base^(length-1) を計算
    power = 1
    for _ in range(length - 1):
        power = (power * base) % mod
    
    hashes = [0] * (n - length + 1)
    
    # 最初の部分文字列のハッシュを計算
    h = 0
    for i in range(length):
        h = (h * base + ord(s[i])) % mod
    hashes[0] = h
    
    # ローリングハッシュで残りの部分文字列のハッシュを計算
    for i in range(n - length):
        h = ((h - ord(s[i]) * power) % mod * base + ord(s[i + length])) % mod
        if h < 0:
            h += mod
        hashes[i + 1] = h
    
    return hashes
```

## 12. ハッシュを使ったテクニック

### 12.1 集合や多重集合の管理

```python
from collections import Counter

# 出現頻度のカウント
text = "abracadabra"
counter = Counter(text)
print(counter)  # Counter({'a': 5, 'b': 2, 'r': 2, 'c': 1, 'd': 1})

# 最も頻度の高い要素
print(counter.most_common(2))  # [('a', 5), ('b', 2)]

# 2つのカウンターの演算
counter1 = Counter("abcaba")
counter2 = Counter("bcdbcd")
print(counter1 + counter2)  # 要素ごとに加算
print(counter1 - counter2)  # 正の差分のみ保持
```

### 12.2 defaultdictを使った効率的な集計

```python
from collections import defaultdict

# 通常の辞書では存在しないキーを参照するとエラー
normal_dict = {}
try:
    normal_dict["key"] += 1  # KeyError
except KeyError:
    pass

# defaultdictは存在しないキーに対してデフォルト値を返す
count_dict = defaultdict(int)  # デフォルト値は0
count_dict["key"] += 1  # OK
print(count_dict)  # defaultdict(<class 'int'>, {'key': 1})

# グループ化の例
words = ["apple", "banana", "cherry", "date", "apple", "banana"]
groups = defaultdict(list)
for word in words:
    groups[len(word)].append(word)
print(groups)  # {5: ['apple', 'apple'], 6: ['banana', 'banana', 'cherry'], 4: ['date']}
```
