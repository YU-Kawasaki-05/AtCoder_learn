# D - Transmission Mission 問題の詳細解説

## 問題の本質

この問題の本質は、「数直線上の点をM個のグループに分け、各グループ内の点をカバーするために必要な電波強度の総和を最小化する」ことです。

## 問題の言い換えとアプローチ

### 基本的な観察

まず、一つのグループ内の家をすべてカバーするのに最適な基地局の配置は、そのグループの最小座標 X_min と最大座標 X_max の中間点です。

このとき、必要な電波強度は：

```
電波強度 = ⌈((X_max - X_min) / 2)²⌉
```

ここで「⌈x⌉」は x を超えない最小の整数（天井関数）を表します。

### 二分探索によるアプローチ

この問題を解くための別のアプローチとして、二分探索を使う方法があります。

「電波強度の総和が K 以下で全ての家をカバーできるか？」という判定問題を考えます。この判定を高速に行うことができれば、二分探索で最小の K を求められます。

#### 判定アルゴリズム

電波強度の上限が K のとき、以下のようなグリーディなアルゴリズムで判定できます：

1. 最初の家をカバーする基地局を配置する
2. その基地局でカバーできる最も遠い家を見つける
3. その家の次の家から再びステップ1を繰り返す
4. 使用した基地局の数が M 以下であれば条件を満たす

```python
def can_cover_all_houses(X, M, K):
    # 家の座標をソート
    X.sort()
    
    # 必要な基地局の数をカウント
    count = 0
    i = 0
    n = len(X)
    
    while i < n:
        # 現在の家をカバーする基地局を設置
        count += 1
        if count > M:
            return False
        
        # この基地局でカバーできる最も遠い家を見つける
        current_pos = X[i]
        radius = K**0.5  # 電波の届く範囲の半径
        
        # 次の家を探す
        while i < n and X[i] <= current_pos + 2 * radius:
            i += 1
    
    return True
```

#### 二分探索の実装

```python
def min_total_power(X, M):
    n = len(X)
    X.sort()
    
    # 二分探索の範囲を決定
    # 最大の電波強度は、全ての家を1つの基地局でカバーする場合
    max_power = ((X[-1] - X[0]) / 2) ** 2
    if max_power % 1 > 0:
        max_power = int(max_power) + 1
    else:
        max_power = int(max_power)
    
    left = 0
    right = max_power
    
    while left < right:
        mid = (left + right) // 2
        if can_cover_all_houses(X, M, mid):
            right = mid
        else:
            left = mid + 1
    
    return left
```

## 動的計画法によるアプローチ

もう一つのアプローチとして、動的計画法を使う方法があります。

`dp[i][j]` を「最初の i 個の家を j 個の基地局でカバーするのに必要な最小の電波強度の総和」と定義します。

遷移は次のようになります：
- 新しい基地局で家 k+1 から i までをカバーすると考える
- 家 1 から k までを j-1 個の基地局でカバーする

```python
def min_total_power_dp(X, M):
    n = len(X)
    X.sort()
    
    # dp[i][j]: 最初のi個の家をj個の基地局でカバーする最小コスト
    dp = [[float('inf')] * (M + 1) for _ in range(n + 1)]
    dp[0][0] = 0
    
    for i in range(1, n + 1):
        for j in range(1, min(i, M) + 1):
            for k in range(i):
                # 新しい基地局で家 k+1 から i までをカバー
                if k == i - 1:
                    # 家が1つだけの場合
                    power = 0
                else:
                    radius = (X[i-1] - X[k]) / 2
                    power = (radius ** 2)
                    if power % 1 > 0:
                        power = int(power) + 1
                    else:
                        power = int(power)
                
                dp[i][j] = min(dp[i][j], dp[k][j-1] + power)
    
    return dp[n][M]
```

## さらなる考察

問題文にある例を使って考えてみましょう：

```
7 3
5 5 8 10 15 15 20
```

最適解は6です。どのように得られるのでしょうか？

1. グループ1：座標5, 5, 8の家
   - 中間点：(5+8)/2 = 6.5
   - 電波強度：((8-5)/2)² = 2.25 → 3

2. グループ2：座標10の家
   - 中間点：10
   - 電波強度：0

3. グループ3：座標15, 15, 20の家
   - 中間点：(15+20)/2 = 17.5
   - 電波強度：((20-15)/2)² = 2.25 → 3

合計電波強度：3 + 0 + 3 = 6

この分割方法がなぜ最適なのかを考えると、「各区間の最大-最小の差の2乗の和」を最小化していることがわかります。

## まとめ

この問題は、一見単純そうに見えても、最適解を求めるには慎重な考察が必要です。アプローチとしては：

1. 貪欲法：隣接する家の距離が大きい場所で区切る
2. 二分探索：電波強度の上限を二分探索する
3. 動的計画法：状態遷移を定義して最適解を求める

どのアプローチも問題の性質を理解するのに役立ちます。実際のコンテストでは、問題の制約に応じて適切な方法を選択することが重要です。
